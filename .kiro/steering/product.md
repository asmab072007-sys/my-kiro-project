# Product Overview

## Project: TodoFlow

TodoFlow is a lightweight, client-side To-Do list web application built for the Kiro University Build-Along challenge.

**Purpose:** Help users manage daily tasks with priorities, due dates, search, and filters — all without a backend.

**Target users:** Individuals who want a fast, private, no-signup task manager that works in any browser.

**Core value:** Zero friction — open the browser, start adding tasks, data persists automatically.

## Key Features

- Add, edit, delete, complete tasks
- Set priority (Low / Medium / High)
- Set due date with overdue detection
- Filter by All / Active / Completed
- Search tasks by text
- Task counters (total, active, completed)
- localStorage persistence — no backend required
- Responsive UI — works on mobile and desktop

## Non-Goals (for this challenge)

- No user authentication
- No server-side storage
- No external APIs
- No complex state management library
